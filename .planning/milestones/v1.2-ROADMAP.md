# Milestone v1.2 Archive: Dark Theme & Granular Permissions

## Summary
**Shipped:** 2026-06-02
**Goal:** Make the dashboard use a deliberate dark theme and replace scattered plan checks with a central, enforceable permissions foundation.

## Key Accomplishments
- **App-Controlled Dark Theme**: Removed "system" theme dependency and established a deterministic dark dashboard experience across all components and pages.
- **Centralized Permission Matrix**: Defined a unified `PlanType` and capability model in `lib/plans.ts`, serving as the single source of truth for access control.
- **Server-Side Route Guards**: Activated root `middleware.ts` with Next.js Edge functions to block Pro/Premium routes (Workers/Reports) before page rendering.
- **Hardened Database Security**: Implemented plan-aware RLS policies on the `workers` table, preventing unauthorized data access at the database level.
- **Secured Free Trials**: Resolved the v1.1 trial bypass vulnerability by shifting trial expiration enforcement from client-side mutations to middleware and RLS.

## Phase History
- **Phase 7: Dark Theme Foundation** - Established the dark visual baseline and updated shared UI primitives.
- **Phase 8: Plan Persistence & Permission Matrix** - Added `profiles.plan` schema, central permission matrix, and trial selection logic.
- **Phase 9: UI Permission Integration** - Standardized plan badges, locked overlays, and upgrade messaging across the dashboard.
- **Phase 10: Route Guards & Permission States** - Implemented server-side and database-level security guards for Pro/Premium features.
