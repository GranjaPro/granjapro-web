# Milestone Requirements: v1.3 - Functional MVP & Integrations

## Vision
Deliver a fully functional, monetization-ready, and security-hardened MVP of GranjaPro by the end of July. Focus purely on database integrations, payment flow, water/health loops, and user feedback mechanisms.

---

## 1. Stripe Payment Integration

### Goal
Implement a subscription-based payment wall using Stripe Checkout to allow users to upgrade/downgrade their tier.

### Requirements
- **Plan Selection Screen**: Update `/dashboard/select-plan` to call a Next.js API route to initiate Stripe Checkout.
- **Stripe Checkout Session**: Implement the `/api/checkout` API route to create Stripe checkout sessions for monthly plans ("Essencial", "Pro", "Premium").
- **Webhooks Integration**: Implement `/api/webhooks/stripe` to securely receive event notifications (e.g. `checkout.session.completed`, `customer.subscription.deleted`) and update the user's `plan` in the `profiles` table.
- **RLS/Route Protection**: Ensure plan-based locks are respected across routes and database operations.

---

## 2. Inventory Management (Database Integration)

### Goal
Connect the inventory management module directly to the Supabase database.

### Requirements
- **DB CRUD**: Fully connect the inventory page to the `inventory` table in Supabase.
- **Form Inputs**: Update stock registration forms to support the fields: Storage Type, Current Qtd, Measuring Unit, Total Stock Value, Expiration Date, and Daily Consumption.
- **Stock Tracking**: Display status badges (Normal, Alert, Critical) and calculate expiration warnings.

---

## 3. Tasks & Notifications System

### Goal
Provide database-backed checklists and automated alerts for farm activities.

### Requirements
- **Task Management**: Implement the `/dashboard/tasks` page with full database-backed CRUD (Option B schema update).
- **Today Checklist**: Integrate the dashboard checklist component with the database tasks instead of React state.
- **Dynamic Alerts**: Connect the alerts panel to the database `alerts` table and auto-trigger stock alerts or laying rate warning notifications.
- **Evaluation Triggers**: Periodically trigger a dynamic system alert/notification asking the user to evaluate the app after a defined active period.

---

## 4. Water Flow & Health History Details

### Goal
Implement real-time water tracking and connect mock details pages to the database.

### Requirements
- **Unified Feed & Water**: Rename menu and page headers to "Gestão de ração e água" / "Ração e água".
- **Water Consumption**: Add `water_consumption_liters` to the `feed_consumption` table. Save water quantity from the feed modal, and show real database metrics in charts/KPIs.
- **Lote Water Page**: Update `agua/page.tsx` under flocks details to query actual `feed_consumption` records for that flock.
- **Lote Health History**: Update `historico-sanitario/page.tsx` under flocks details to display actual events loaded from `health_records` instead of hardcoded `mockEvents`.

---

## 5. Feedback Collection System

### Goal
Collect user experience ratings, bugs, and general feedback directly in the app.

### Requirements
- **Feedback Page**: Create `/dashboard/feedback` page ("Conte-nos sua experiência") with star rating (1-5), category selector, and description.
- **Access Points**: Add link to the feedback page at the end of the sidebar navigation, and a button inside the Profile Settings modal.
- **Database Persistence**: Save feedbacks in a `feedbacks` table with appropriate foreign keys (`user_id`, `farm_id`).

---

## 6. KPI Goals & Target Ranges

### Goal
Define and display targets across all pages for performance and loss metrics.

### Requirements
- **Customizable Dashboard Goals**: Allow users to click on dashboard KPI cards to open a modal and set custom targets (persisted in `kpi_goals` table).
- **Built-in Quality & Loss Targets (Produção)**: Display fixed reference ranges in the production detail views:
  - Ovos Trincados ou Quebrados: 3% a 5% da produção total.
  - Ovos Sujos: 1% a 2% da produção total.
  - Ovos Deformados ou Sem Casca: 1% a 1,5% da produção total.
  - Anormalidades Internas: Menos de 0,5% da produção total.
- **Built-in Feed Consumption Targets (Ração)**: Reference range of 110g to 130g of feed per bird/day. Display visual alerts on deviations.
- **Built-in Stage-based Water Consumption Targets (Água)**: Target ranges based on bird age/development stage (55ml to 245ml per bird/day).
