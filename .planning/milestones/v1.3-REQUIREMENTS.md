# Milestone Requirements: v1.3 - Inventory, Tasks & UI Consolidation

## Vision
Consolidate the dashboard experience by standardizing data entry (forms), completing the inventory/task core loops, and refactoring large pages into clean, reusable components.

---

## 1. Form Standardization & Validation

### Goal
Replace scattered, manually-managed form states with a centralized component driven by Zod schemas.

### Requirements
- **Centralized Component**: Create a `RegistrationForm` or `FormField` collection that handles label, input, and error states uniformly.
- **Zod Integration**: Define strict schemas for:
  - Barns/Galpões
  - Flocks/Lotes
  - Production/Produção
  - Inventory/Estoque
  - Sales/Vendas
  - Feed/Raçao
  - Health/Saúde
  - Mortality/Mortalidade
  - Finances/Finanças
  - Customers/Clientes
  - Equipments/Equipamentos
- **Validation**: Enforce required fields, numeric constraints (e.g., no negative birds), date ranges and put input mask where are necessary.
- **UI Consistency**: Ensure all forms use the same spacing, focus states, and error messaging.

---

## 2. Inventory Management (Full Integration)

### Goal
Move the inventory page from local state/mock-up to a fully functional database-backed module.

### Requirements
- **DB CRUD**: Fully connect the inventory page to the `inventory` table in Supabase.
- **Stock Tracking**: Implement logic for "low stock" alerts (e.g., when current quantity < threshold).
- **Consumption Sync**: (Bonus) Link feed consumption inputs to decrement inventory quantity automatically.
- **Categorization**: Support for Feed, Medications, Equipment, and Packaging.

---

## 3. Tasks & Notifications System

### Goal
Establish a proactive management system for farm activities and critical alerts.

### Requirements
- **Task Management Page**: A dedicated view to create, schedule, and complete recurring tasks (e.g., "Vaccination", "Cleaning").
- **In-App Notifications**:
  - Alert users when an inventory item is low.
  - Notify when a task is overdue.
  - (Future) Alert on productivity drops (laying rate < target).
- **Dashboard Integration**: Update the dashboard `TasksChecklist` to pull from the new centralized task system.

---

## 4. Reports Refinement & Export

### Goal
Ensure reports are accurate, performant, and exportable.

### Requirements
- **Data Accuracy**: Verify that all report charts (Production, Mortality, Finances) use real Supabase data without fallbacks.
- **PDF/CSV Export**: Refine the `jsPDF` and `ExcelJS` implementation for better formatting and local currency/units support.
- **Performance**: Move heavy data transformation logic out of the `reports/page.tsx` into a `lib/services/reports.ts`.

---

## 5. UI Polish & KPI Customization

### Goal
Improve user engagement through interactive and customizable dashboard elements.

### Requirements
- **Customizable KPI Goals**: Allow users to click on a KPI (e.g., "Laying Rate") and set their own target goal, which is then saved to their profile/farm record.
- **Componentization**: Refactor `inventory/page.tsx` and `reports/page.tsx` into atomic components (e.g., `InventoryTable`, `StockStatusCard`, `ReportChart`).
- **Standardized Graphics**: Ensure all Recharts components across different pages use the same styling and tooltips.

---

## Out of Scope
- External payment gateway integration.
- Public API for third-party integrations.
- Native mobile push notifications (keeping it as web-based alerts for now).
