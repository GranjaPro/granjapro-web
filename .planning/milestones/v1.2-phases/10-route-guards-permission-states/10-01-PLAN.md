  <files>lib/supabase/middleware.ts</files>
  <behavior>
    - If user is authenticated and accessing '/dashboard/workers' or '/dashboard/reports':
      - Fetch 'plan' and 'trial_ends_at' from 'profiles'.
      - If plan is not 'pro' or 'premium' (or trial is expired):
        - Redirect to '/dashboard/select-plan'.
    - Ensure DB query only runs for these specific protected routes to minimize latency.
    - Use 'hasMinimumPlan' and trial helper logic from 'lib/plans.ts' if compatible with Edge, otherwise implement inline.
  </behavior>
  <action>
    Refactor `updateSession` in `lib/supabase/middleware.ts` to:
    1. Define `PROTECTED_ROUTES = ['/dashboard/workers', '/dashboard/reports']`.
    2. Check if the current request pathname starts with any protected route.
    3. If yes and user is logged in, fetch the profile metadata.
    4. Validate the plan and trial status.
    5. Issue a `NextResponse.redirect` to `/dashboard/select-plan` if unauthorized per D-01 and D-03.
  </action>
  <verify>
    <automated>Mock a session with an 'essencial' plan and verify a 307 redirect when requesting /dashboard/workers.</automated>
