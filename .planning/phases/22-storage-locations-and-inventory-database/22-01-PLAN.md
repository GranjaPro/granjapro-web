<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client/Supabase SQL -> inventory tables | Untrusted row writes enter farm-scoped inventory tables and trigger financial side effects. |
| inventory tables -> financial_transactions | Database triggers create, update, or delete generated expense rows. |
| inventory_losses -> specialized inventory tables | Loss inserts mutate stock quantities in the same transaction. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-01 | Information Disclosure | New inventory tables | mitigate | Enable RLS on every new table and scope select policies by farm ownership/profile membership. |
| T-22-02 | Tampering | location_id assignment | mitigate | Trigger verifies location farm_id, active status, and expected category before inventory insert/update. |
| T-22-03 | Tampering | generated expenses | mitigate | Use unique reference and update/delete-by-reference trigger behavior instead of duplicate inserts. |
| T-22-04 | Tampering | inventory_losses | mitigate | Before-insert trigger validates positive quantity, sufficient stock, and typed same-farm item linkage before decrement. |
| T-22-05 | Repudiation | location deletion | mitigate | Linked locations are deactivated instead of deleted so historical inventory/loss records remain explainable. |
| T-22-SC | Tampering | npm/pip/cargo installs | accept | No package installation is planned for this phase. |
</threat_model>
