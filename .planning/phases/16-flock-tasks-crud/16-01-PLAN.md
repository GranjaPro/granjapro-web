# Plan: 16-01 - Flock Tasks CRUD

## 1. Goal
Implement CRUD for flock tasks, adding `category`, `priority`, and `recurrence` to the `tasks` table, and implementing dynamic recurrence in the UI with a `task_exceptions` table for tracking completions.

## 2. Changes

### Database
- Create migration to add `category`, `priority`, `recurrence`, `notes` to `tasks`.
- Create `task_exceptions` table with RLS to track `done`, `missed`, or `skipped` states for dynamically generated task occurrences.

### Backend (`lib/services/tasks.ts`)
- Add/update functions to manage `tasks` and `task_exceptions`.
- `toggleTask` will now operate on `task_exceptions` for a specific date rather than the base task.

### Frontend
- Create a `TaskDialog` component to handle creating and editing tasks.
- In `app/dashboard/flocks/detalhes/[loteId]/operacional/page.tsx`, remove mock data. Fetch base tasks and exceptions, then dynamically expand recurring tasks to fill the list.
- Map the icons automatically based on `TaskCategory`.

## 3. Verification
- Create a recurring task and mark one occurrence as done. Verify future occurrences remain pending.
- Ensure the CRUD UI handles all new fields properly.
