# Phase 23 Plan 04: UAT Gap Closure

  - **Action:** Add a configuration modal or field allowing the user to set a percentage or threshold for low stock alerts (e.g., "Alert when feed < X%").

- [ ] **Task 4: Universal Default Location**
  - **File:** `lib/services/inventory.ts`
  - **Action:** Ensure "Sem local definido" acts as a fallback or universal instance for all products if no specific location is selected.
