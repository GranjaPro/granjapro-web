# Plan 09-01: Shared Permission Primitives Normalization

**Phase:** 9 - UI Permission Integration  
**Status:** Ready  
**Requirements:** PERM-02, PERM-03

<objective>
Normalize the permission primitives so all touched UI surfaces consume the same plan metadata and helper semantics before page-level cleanup.
</objective>

## Scope

In scope:
- Align shared badge/lock/upgrade primitives to one canonical behavior.
- Reduce repeated ad-hoc plan checks in shell-level code.
- Guarantee plan tags and required-plan badges come from one component pathway.

Out of scope:
- Route/API hard enforcement (Phase 10).
- Deep page-by-page autolayout fixes (Plan 09-02).
- AI usage meter final integration (Plan 09-03).

<tasks>

### 09-01-01. Standardize required-plan tag rendering

**Type:** implementation  
**Files:** `components/plan/plan-badge.tsx`, `components/plan/required-plan-badge.tsx`, `lib/plans.ts`

**Action:**
- Ensure all plan labels (Pro/Premium/active account tags) come from shared badge primitives.
- Align badge tone and color token usage to the currently accepted UI palette.
- Keep conditional visibility rules centralized: only show upsell tags when user lacks required plan.

**Verify:**
- `rg -n "PlanBadge|RequiredPlanBadge" components app/dashboard`

### 09-01-02. Normalize lock overlay primitive contract

**Type:** implementation  
**Files:** `components/plan/locked-overlay.tsx`

**Action:**
- Ensure overlay keeps parent radius and safe stacking context.
- Preserve visible card header (icon/title/subtitle/tag) while blocking protected body.
- Expose reusable props for message/title/required-plan consistency used by all pages.

**Verify:**
- `rg -n "border-radius|rounded|z-|overlay|requiredPlan" components/plan/locked-overlay.tsx`

### 09-01-03. Replace shell-level repeated checks with helper predicates

**Type:** implementation  
**Files:** `app/dashboard/layout.tsx`, `components/plan/upgrade-popup.tsx`, `lib/plans.ts`

**Action:**
- Replace touched repeated checks like `plan === "essencial"` / `plan !== "premium"` with shared helper predicates.
- Keep current behavior for navigation gating and advanced-feature toggle visibility.
- Ensure upgrade popup references centralized plan definitions.

**Verify:**
- `rg -n "plan === \"essencial\"|plan !== \"premium\"" app/dashboard/layout.tsx components/plan/upgrade-popup.tsx`
- `npm run build`

</tasks>
