# Plan 09-02: Page-Level Locking and Autolayout Coherence

**Phase:** 9 - UI Permission Integration  
**Status:** Ready  
**Requirements:** PERM-02, PERM-03, SEC-02

<objective>
Apply the normalized permission primitives to high-impact dashboard pages so locked states are consistent, protected data remains blocked, and layout reflows cleanly when advanced sections are hidden.
</objective>

## Scope

In scope:
- Harmonize lock behavior on dashboard, production, health, mortality, finances, clients, sales, and feed pages.
- Remove empty wrappers/div shells left behind when toggle hides advanced sections.
- Keep title/subtitle/tag visible while blocking protected card bodies.

Out of scope:
- Backend/route hard guards.
- Non-dashboard sections not touched in this milestone.

<tasks>

### 09-02-01. Normalize locked card composition across touched pages

**Type:** implementation  
**Files:** dashboard pages listed in frontmatter

**Action:**
- Ensure each advanced card uses the same locked composition pattern.
- Prevent protected body details from rendering above overlay in locked state.
- Keep visible context (feature title + required plan tag) for upgrade clarity.

**Verify:**
- `rg -n "LockedOverlay|requiredPlan|RequiredPlanBadge" app/dashboard`

### 09-02-02. Fix toggle-driven autolayout collapse

**Type:** implementation  
**Files:** dashboard pages listed in frontmatter

**Action:**
- Remove empty placeholders when components are hidden by toggle.
- Rebalance grid/flex spans so visible cards fill layout naturally.
- Resolve known spacing artifacts between KPI rows and chart rows.

**Verify:**
- `npm run build`

### 09-02-03. Ensure secure-by-UI rendering order in locked regions

**Type:** implementation  
**Files:** dashboard pages listed in frontmatter

**Action:**
- Gate protected content branches before expensive/protected render paths where practical.
- Keep non-sensitive summaries and labels visible without leaking restricted values.
- Reuse shared helper predicates instead of local literal checks.

**Verify:**
- `rg -n "plan === \"essencial\"|plan !== \"premium\"" app/dashboard`
- `npm run build`

</tasks>
