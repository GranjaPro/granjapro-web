<threat_model>
## ASVS Level

Level 1. Mitigate high and critical threats. Mitigate medium threats on the primary client-to-Supabase trust boundary. Accept low threats only with rationale.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> React form state | Rating, category, and description are untrusted browser input. |
| React page -> feedback service -> Supabase | Client payload crosses to persistence and must rely on RLS and constraints for authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-18-05 | Tampering | `app/dashboard/feedback/page.tsx` submit payload | medium | mitigate | Validate rating/category before submit for UX, but rely on Plan 01 database constraints and RLS as authoritative controls. |
| T-18-06 | Spoofing | Missing or stale auth/farm context | medium | mitigate | Disable submit until `user.id` and `farm.id` are present and include both IDs in the typed insert payload. |
| T-18-07 | Information Disclosure | Submit error rendering | low | mitigate | Show generic inline retry copy and avoid rendering raw Supabase error details to the user. |
| T-18-08 | Information Disclosure | Optional description text | medium | mitigate | Do not render submitted feedback history in this phase; only local textarea content and transient status are shown. |
| T-18-SC | Tampering | npm/package installs | high | mitigate | Do not install packages or initialize new UI registries; use existing React, Tailwind, local UI primitives, and lucide-react. |
</threat_model>
