# Granja Pro – User Flows

## Onboarding Flow

1. User signs up
2. Onboarding wizard appears
3. User enters farm information
4. User enters number of barns
5. User enters bird count
6. Dashboard is generated

## Daily Farm Flow

Typical daily usage:

1. Farmer opens dashboard
2. Checks production metrics
3. Enters egg production
4. Enters feed consumption
5. Logs mortality
6. Reviews tasks
7. Reviews financial metrics

## Sales Flow

1. Register customer
2. Register sale
3. Record payment
4. Update financial dashboard

## Decision Flow

Farmer checks:

- production trend
- feed cost
- mortality

Then makes operational decisions.
