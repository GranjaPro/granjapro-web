# Granja Pro – Product Vision

## Product Overview

Granja Pro is a farm management SaaS for poultry egg producers.

It acts as the **daily control center of the farm**.

The platform helps farmers:

- monitor egg production
- track feed consumption
- track mortality
- manage farm finances
- manage customers
- track daily operations
- make better operational decisions

## Target Users

Primary users:

- small egg producers
- medium egg producers
- family farms
- cage-free farms
- free-range farms

## Product Philosophy

The product must be:

- extremely simple
- useful daily
- mobile-first
- fast to learn
- practical

Farmers should be able to use it within **minutes**.

## Core Value

Granja Pro helps farmers:

- reduce waste
- increase productivity
- improve financial control
- simplify daily farm management

## Infrastructure

The platform uses Supabase as the backend infrastructure layer.

Supabase provides:

- managed PostgreSQL database
- authentication system
- automatic REST APIs
- realtime data updates
- file storage

This architecture allows the product to launch faster while maintaining scalability.

Frontend applications interact directly with Supabase APIs.
