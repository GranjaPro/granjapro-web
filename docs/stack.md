# Granja Pro – Technology Stack

## Overview
Granja Pro is a modern SaaS platform designed for small and medium poultry egg farmers.  
The system must be mobile-first, simple, fast, and optimized for daily farm operations.

## Architecture

Frontend:
- Next.js
- React
- TailwindCSS
- Mobile-first design

Backend:
- Node.js
- REST API architecture

Database:
- PostgreSQL

Authentication:
- JWT based authentication

Deployment (future):
- Docker
- Cloud provider (AWS / Vercel / Railway)

## Principles

- Simple architecture
- Modular backend
- Reusable UI components
- Mobile-first interface
- Clean and maintainable code

## UI Design

The UI should follow these rules:

- Large touch-friendly components
- Clear hierarchy
- Minimal friction for data entry
- Agritech aesthetic
- Green/earth color palette
- Fast loading

The target user often uses a **smartphone in the farm environment**.
