## Table Descriptions

users
System users.

farms
Farm entities.

barns
Barn structure inside farms.

flocks
Groups of birds.

egg_production
Daily egg production data.

feed_consumption
Feed usage tracking.

mortality
Bird mortality records.

financial_transactions
Income and expenses.

customers
Egg buyers.

sales
Sales records.

tasks
Daily farm tasks.

alerts
System notifications.
