# Granja Pro – MVP Scope

The MVP focuses on **high daily value features**.

Avoid complexity. Focus on usability.

## MVP Modules

### Authentication
- Login
- Signup
- Password recovery

### Onboarding
Ask the farmer:

- farm name
- producer name
- production system
- number of barns
- total birds
- main breed
- sells eggs directly?
- wants financial tracking?

After onboarding generate a ready dashboard.

### Farm Management
- Farm registration
- Barn registration
- Capacity per barn
- Production system per barn

### Flock Management
- flock name
- breed
- arrival date
- number of birds
- assigned barn
- production start date
- peak estimate

### Egg Production
Daily input:

- eggs produced
- broken eggs
- dirty eggs
- discarded eggs
- eggs sold
- egg price

Auto calculations:

- laying rate
- eggs per bird
- production trends

### Feed Management
Track:

- feed quantity
- feed cost
- feed type

Auto calculations:

- feed per flock
- feed cost per egg

### Mortality Tracking
Daily input:

- dead birds
- suspected cause

System calculates:

- mortality rate
- mortality trends

### Financial Management

Revenue:
- egg sales
- other income

Expenses:
- feed
- medicines
- labor
- utilities
- maintenance

Features:
- cash flow
- monthly profit
- cost per egg

### Customer Management
Customers:

- markets
- restaurants
- distributors
- direct buyers

Store:

- name
- phone
- location
- payment terms

### Sales
Track:

- quantity sold
- egg type
- price
- payment status

### Tasks
Daily tasks:

- collect eggs
- feed birds
- clean barn
- inspect birds

Checklist style interface.

### Dashboard
Main KPIs:

- eggs produced today
- laying rate
- active birds
- mortality today
- feed cost today
- revenue this month
- expenses this month
- profit estimate

### Reports
Export:

- production report
- mortality report
- feed report
- financial report
